# Video Editor Workspace

Không gian làm việc và thử nghiệm các công cụ dựng/render video bằng code và giao diện web.

## Các dự án con

- [`mike-editor/`](./mike-editor) — Trình chỉnh sửa video timeline nền web (Node.js HTTP server trên port `5230`) hỗ trợ LUT màu, VFX filters, keyframes, transitions, text styles và thư viện SFX/BGM tự tạo.
- [`hcm-intro/`](./hcm-intro) — Dự án video giới thiệu TP.HCM dựng bằng Hyperframes (`hyperframes@0.9.44`).
- [`hyperframes-demo/`](./hyperframes-demo) — Dự án demo Hyperframes.
- [`remotion-demo/`](./remotion-demo) — Dự án demo Remotion (`@remotion/cli`, React 19).
